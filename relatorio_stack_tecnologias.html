1. Visão Executiva & Contexto do Projeto

O Anjos da Praia é uma plataforma web e Progressive Web App (PWA) de missão crítica, concebida para mitigar e solucionar com máxima agilidade o desaparecimento temporário de crianças nas praias de Guarapari (ES). Em momentos de alta lotação na orla, a perda de contato visual causa desespero imediato aos pais e sobrecarga aos postos de socorro.

O pilar central do projeto é a fricção zero: o banhista que localiza uma criança não precisa instalar aplicativo, efetuar cadastro ou criar senhas. Apenas aponta a câmera do celular para o QR Code da pulseira e, em um único toque, envia a coordenada GPS exata para os operadores dos postos e salva-vidas.

Conformidade e Sigilo (LGPD): O banhista que escaneia a pulseira jamais visualiza o nome da criança, telefones ou identidade dos responsáveis. Todos os dados sensíveis ficam protegidos no backend e são acessíveis exclusivamente aos operadores autenticados do sistema.

3. Ciclo de Vida da Ocorrência

[Família / Criança] ──▶ [Tenda / Posto de Apoio] (Cadastro no sistema & fixação da pulseira impermeável) │ ▼ (Caso a criança se afaste momentaneamente) [Banhista Escaneia QR Code] ──▶ Abre URL web direta (/alerta?pulseira=XXXX) sem baixar app │ ▼ [Banhista Clica "Enviar Minha Localização"] ──▶ Captura GPS nativo (HTML5 Geolocation API) │ ▼ [Disparo Supabase Realtime via WebSockets] ──▶ Alerta sonoro (sirene) & modal no Painel Admin (/admin) ├─▶ Plotagem automática no Mapa Leaflet com círculo de precisão (m) ├─▶ Cálculo de proximidade (Fórmula de Haversine) identificando o posto mais perto ├─▶ 1-Clique: "Traçar Rota no Google Maps" para direcionar o socorrista em campo └─▶ 1-Clique: Acionar Responsáveis via Ligação ou WhatsApp com mensagem pronta │ ▼ [Linha do Tempo de Auditoria]: 1. Criança localizada ➔ 2. Equipe a caminho ➔ 3. Criança recebida ➔ 4. Responsáveis localizados ➔ 5. Reencontro realizado 🎉 (Status terminal com bloqueio imutável)

4. Módulos e Funcionalidades Principais

📍 Módulo do Banhista (/alerta)

Interface ultrarresponsiva para envio emergencial de GPS em até 3 segundos, dispensando login ou formulários.

🔔 Monitoramento Realtime

Sincronização reativa de novos chamados com sirene de alerta configurável e notificações toast para o operador.

🗺️ Mapa Geoespacial Interativo

Visualização com tiles Esri, pinos coloridos por status, rota automatizada e medição de distância em metros.

🗂️ Gestão de Cadastros de Pulseiras

CRUD integral de pulseiras com busca instantânea por número ou responsável, dados médicos e tenda emissora.

🏖️ Base Oficial de Praias & Postos

Tabela relacional com 32 praias catalogadas de Guarapari com GPS padrão para agilizar o cadastro de novos postos.

⛺ Alocação de Operador por Posto

Associação do operador autenticado ao posto em operação no Supabase com botão 1-clique e indicador na barra lateral.

📜 Auditoria com Histórico Cronológico

Trilha gravada em JSONB com data/hora exata (dd/mm/aaaa hh:mm:ss) e operador para cada alteração de status.

🖨️ Impressão em Massa & Relatórios

Geração de folhas de etiquetas com QR Code em grade para gráfica e exportação de base de ocorrências em CSV.

5. Modelo Relacional de Dados (PostgreSQL / Supabase)

Tabela Chaves e Campos Críticos Função no Sistema
praias id (PK), nome (UK), latitude_padrao, longitude_padrao Catálogo mestre das praias de Guarapari para alimentação de seletores e GPS.
tendas id (PK), nome, praia_id (FK), latitude, longitude, ativa Cadastro físico dos postos de salvamento e bases de apoio na orla.
cadastros_pulseiras id (PK), numero_pulseira (UK), nome_responsavel, telefone Armazenamento sigiloso dos dados familiares vinculados ao código da pulseira.
ocorrencias id (PK), numero_pulseira (FK), status, historico_status (JSONB) Chamados de alerta gerados na praia com histórico completo de auditoria.
operadores id (PK -> auth.users), nome, email, tenda_id (FK) Registro dos operadores do sistema com seu posto de operação vinculado.
Conclusão Técnica: A solução conjuga velocidade de carregamento em borda, resiliência de dados em PostgreSQL e tempo de resposta imediato via WebSockets, garantindo aos guarda-vidas e familiares uma ferramenta decisiva na proteção das crianças nas praias.
